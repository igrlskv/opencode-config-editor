# Установка плагина Config Editor (инструкция для новичков)

Плагин добавляет в OpenCode Desktop редактор конфига: выбор моделей провайдера кликом,
назначение модели по умолчанию, проверка конфига на ошибки. Всё в интерфейсе, без правки
JSON руками.

Работает с **OpenCode Desktop 2.3.x** (см. «Совместимость» в README). Есть три способа
установки — выберите **один**:

| Способ | Кому подходит |
|---|---|
| [Вариант 1: ZIP с GitHub](#вариант-1-скачать-zip-с-github-проще) | Просто попробовать. Без командной строки |
| [Вариант 2: GitHub Release](#вариант-2-скачать-release-zip-минимум-файлов) | Минимум файлов на диске |
| [Вариант 3: git clone + сборка](#вариант-3-git-clone-и-сборка-для-разработчиков) | Хочется править код или держать актуальную версию из main |

После установки любым способом: [шаг «Подключить»](#шаг-2-подключить-плагин-в-конфиге-opencode)
и [проверка](#шаг-3-проверить-что-работает).

---

## Вариант 1: скачать ZIP с GitHub (проще)

1. **Установите OpenCode Desktop**, если ещё нет: https://opencode.ai → Download.
   Запустите один раз, затем полностью закройте (в трее тоже).

2. **Скачайте плагин**: откройте https://github.com/igrlskv/opencode-config-editor —
   зелёная кнопка **Code** → **Download ZIP**.

3. **Распакуйте**: правый клик по скачанному файлу → «Извлечь всё…» (Windows) /
   двойной клик (macOS) / `unzip main.zip` (Linux). Появится папка
   `opencode-config-editor-main` — переименуйте её в `opencode-config-editor`.

4. **Положите папку в постоянное место.** Требований к месту нет — главное не удалять его
   потом. Рекомендации: путь без пробелов и кириллицы, не в «Загрузках». Например:
   - Windows: `C:\Tools\opencode-config-editor`
   - Linux: `~/tools/opencode-config-editor`
   - macOS: `~/tools/opencode-config-editor`

   Внутри должны быть папка `dist` с файлом `gui-experimental.cjs` и файл `package.json` —
   это рабочие файлы плагина, они уже собраны.

---

## Вариант 2: скачать Release ZIP (минимум файлов)

Release — это архив только с тремя файлами (собранный плагин, package.json, README),
без исходников:

1. Откройте https://github.com/igrlskv/opencode-config-editor/releases
2. В последнем релизе скачайте **opencode-config-editor-vX.Y.Z.zip** (в секции Assets).
3. Распакуйте в постоянное место — папка и есть плагин, переименовывать не обязательно,
   но путь запомните.

> Release появляется после публикации версии. Если раздел Releases пуст — используйте
> вариант 1.

## Вариант 3: git clone и сборка (для разработчиков)

Нужен [bun](https://bun.sh) (или node+npm):

```sh
git clone https://github.com/igrlskv/opencode-config-editor.git
cd opencode-config-editor
bun install
bun run build        # пересоберёт dist/gui-experimental.cjs
```

Готово — папка клона и есть плагин. Обновление: `git pull && bun install && bun run build`.

## Шаг 2: подключить плагин в конфиге OpenCode

Каталог, где лежит папка плагина, — любой: OpenCode читает путь из конфига.

1. **Откройте глобальный конфиг** (Desktop читает только его):

   | ОС | Путь | Как открыть |
   |---|---|---|
   | Windows | `C:\Users\<вы>\AppData\Roaming\opencode\opencode.json` | Win+R → `%APPDATA%\opencode` → Enter |
   | Linux | `/home/<вы>/.config/opencode/opencode.json` | терминал: `nano ~/.config/opencode/opencode.json` |
   | macOS | `/Users/<вы>/.config/opencode/opencode.json` | Finder → Переход → Папка: `~/.config/opencode` |

   Файла может не быть — создайте пустой `opencode.json` в этой папке.

2. **Впишите путь к папке плагина** в `plugins` (путь абсолютный, слэши обычные `/`):

   ```jsonc
   {
     "plugins": ["C:/Tools/opencode-config-editor"]
   }
   ```

   Linux/macOS:

   ```jsonc
   {
     "plugins": ["/home/имя/tools/opencode-config-editor"]
   }
   ```

   Если конфиг уже непустой — просто добавьте строку с путём в существующий массив `plugins`
   (или создайте массив, если его нет). Не удаляйте остальное содержимое.

3. **Ключ провайдера** (нужен для списка моделей; пропускаете — плагин всё равно заработает,
   но каталог будет пуст/с ошибкой). Проще всего через переменную окружения:

   - Windows: PowerShell → `setx ROUTERAI_API_KEY "sk-ваш-ключ"` → перезапустить OpenCode
   - Linux/macOS: `echo 'export ROUTERAI_API_KEY="sk-ваш-ключ"' >> ~/.bashrc && source ~/.bashrc`
     (для zsh — `~/.zshrc`)

   Либо ключ уже прописан в вашем глобальном конфиге у провайдера (`apiKey`) — плагин сам его
   подхватит оттуда. Вписывать ключ в конфиг плагина не нужно.

## Шаг 3: проверить, что работает

1. Запустите (или полностью перезапустите) OpenCode Desktop.
2. **Settings → Config Editor** (иконка шестерёнки) — открылась страница с секциями
   «Модели провайдера», «JSON целиком», «Валидация».
3. Внутри сессии: «+» в правой панели → «Конфиг», или **Ctrl+Shift+C** — та же страница
   рядом с чатом.
4. В списке моделей появились модели — всё готово.

## Обновление

- Вариант 1: скачайте ZIP заново, замените содержимое старой папки, перезапустите OpenCode.
- Вариант 2: скачайте новый Release.
- Вариант 3: `git pull && bun install && bun run build`.

Конфиг OpenCode (`plugins`, ключи) при этом не трогается.

## Если не работает

| Симптом | Что делать |
|---|---|
| «Config Editor» нет в Settings | Проверьте путь в `plugins` глобального конфига: папка существует, внутри есть `dist/gui-experimental.cjs`; версия OpenCode 2.3+ |
| Красный блок «Плагин не смог отрисоваться» | Нажмите «Повторить»; создайте issue с текстом ошибки |
| Каталог моделей пуст или с ошибкой | Не найден ключ: см. шаг 2.3 выше |
| Другое | создайте issue: https://github.com/igrlskv/opencode-config-editor/issues |

Смотрите также полный README (технические детали, настройка под другого провайдера).
